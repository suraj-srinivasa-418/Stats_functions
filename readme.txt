
This program created in C contains 16 mathematical functions used within statistics and probability. For effective compilation and utilization, not much is required asides a standard IDE (e.g. VSCode,JetBrains,etc.) and the necessary extensions for running C/C++ programs. Within VSCode you can install the C/C++ extension; in addition to this, you will need to download a compiler package such as MinGW and adding it to your bin directory to your system's PATH. This is usually done by editing your environment variables within the environment variables program within your control panel. Download the .c file and run it with gcc and the required extensions.


For the square root function within the program, you will need to compile with the -lm tag at the end with your standard gcc command.
